# pdxplans.org

This is the source code for pdxplans.org, a website that summarizes Medicare plan options for Multnomah & Clackamas counties in Oregon.

The site and files here were developed mostly by AI (Claude), using data from medicare.gov and cms.gov, plan documents from insurance carriers, and summaries of those curated by staff and volunteers from [SHIBA](https://shiba.oregon.gov/).  It is intended to help them in their public service mission, but it is not affiliated with SHIBA or any government agency.

Although we've worked hard to build an accurate data set, and make it easy to cross-check numbers against the official plan documents, there may still be mistakes, and not every figure or citation has been reviewed by a human.
